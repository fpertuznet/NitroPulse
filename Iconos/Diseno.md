# Icono NitroPulse

Generado con la herramienta integrada de imágenes. Concepto: procesador verde, GPU roja y pulso central sobre una pieza cuadrada oscura con esquinas redondeadas; exterior transparente. Se convirtió a ICO de Windows con tamaños 16, 24, 32, 48, 64, 128 y 256 píxeles, conservando el PNG original.

Prompt utilizado:

Use case: logo-brand. Asset: final square Windows application icon for NitroPulse, a CPU/GPU temperature and resource monitoring app. Original compact polished symbol: a bold angular N subtly formed by a pulse waveform, joined to a minimal processor silhouette. Strong silhouette instantly readable at 32 pixels, thick clear shapes. Neon lime green CPU accent and warm vivid red GPU accent against a charcoal rounded-square tile. Flat clean geometric design, very restrained bevel only if needed, no tiny circuit details, no words, no letters outside the monogram, no numerals, no watermark, no mockup, no surrounding scene. Single centered icon occupying 88% of the square canvas. Outside the rounded tile must be truly transparent. Produce only one icon, straight-on.
